# 常见问题

**账号目录怎么选？**

选择实际包含 db_storage 的单个账号目录，或先选 xwechat_files 再从下拉框选账号。界面自动扫描与手动入口均保留。手机备份文件夹不是同一种数据来源。

**是否需要管理员权限？**

不默认要求管理员。无法只读访问选定微信进程时，先核对账号、进程与权限级别。不要关闭系统保护或注入其他程序来绕过错误。

**为何提示 PAGE_AUTH_FAILED / MEDIA_SNAPSHOT_MISSING？**

前者表示有效页认证失败，后者表示语音数据库未能生成可用副本。界面有诊断代码和请求编号；不把它们笼统称作“找不到 VoiceInfo”。不要发送密钥或原数据库，优先提供脱敏诊断与完整软件版本。

**导出后名称中的文字不准确？**

识别文字是本地模型的结果，口音、背景声和短语音会影响效果。原始音频保留；清单内有完整文字和状态，WAV 成功与识别成功分别计数。

**包为何比较大？**

完整包携带离线识别模型、原生运行库与 DirectML，解压后不需下载模型。Git 中模型单独下载，但不删减部署包功能。DirectML 依赖保留不等于已启用 GPU。

**在哪里找日志？**

通过界面“高级 / 诊断 → 导出诊断包”。程序只从固定目录按字段和文件名白名单导出。公开反馈前仍请检查，不上传整个 workspace。

**最新 4.x 一定支持吗？**

不能保证。当前版本允许受限尝试，但必须通过选定来源认证、WAL 和 SQLite 校验。当前 preview18 的真实账号验证尚未完成；上游成功与本工具合成测试不代表相同账号实测成功。
