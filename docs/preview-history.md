# 微信语音导出工坊

Windows x64 桌面小工具：从用户明确选择的电脑微信数据中整理语音，按会话和日期筛选、试听，批量导出原始 SILK、可播放 WAV 和 CSV 清单。独立项目，不依赖 NAS，不需要 GPU 或云端接口；可选的本地识别模型与运行库已随完整包提供。

**当前为 1.0.0-preview18，面向 Windows 微信 4.x。** Weixin.exe/WeChat.exe的4.*.*.*文件版本可尝试连接，不再限定4.0.5.16。已有用户授权账号的真实验证版本为4.0.5.16和4.1.0.30，其他4.x尚未验证。这不代表兼容所有账号、版本和历史语音；找不到密钥、字段不同、本地语音已被清理等情况会如实提示。

preview14把后台引擎换成自研C#引擎，去除Python运行时：加密/快照、密钥提取、索引、SILK解码（pysilk 0.2.8同源SDK编译为silk.dll）与导出管线逐模块与Python参考实现合成对照（含逐字节WAV、CSV与真实模型识别），协议与界面不变。preview15修复识别超时错位、取消遗留解码进程和特殊路径，使用事务加速建索引，补齐源码包的原生编译材料，详见 [preview15-CSharp引擎打磨](preview15-CSharp引擎打磨.md)。尚未经授权真实账号复测，不宣称真实账号兼容；preview13包可作回退。

preview16 加速创建只读副本：复用密码学对象和页缓冲，明文冻结副本减少一次完整复制；显示复制、解密、WAL 和完整性检查进度。同一份约 32 MiB 合成加密库三轮中位耗时从 1.53 秒降至 0.23 秒，详细范围见 [只读副本加速](preview16-只读副本加速.md)。源文件只读，所有修改均在工作目录的副本上完成；读取仍可能占用 CPU 和磁盘。

preview17 修复语音库副本失败后误报 VoiceInfo 的提示，保留页认证、WAL、SQLite 与重试阶段的具体错误代码，详见 [微信4.2对照与诊断](preview17-微信4.2对照与诊断.md)。该版本用于进一步定位真实账号问题，不宣称已经完成 4.2.x 兼容验收。

preview13新增Moect式账号自动扫描：启动即按微信自身配置/注册表/文档定位 `xwechat_files`，把本机含 `db_storage` 的账号列进下拉框并按最近使用排序，点“扫描账号”可重扫，“选择位置”保留手动指定。详情见《preview13-账号扫描》。

preview7打磨日常操作：双击语音试听，切换会话或翻页自动停止；导出页提供全部日期、最近7天、最近30天快捷范围，零结果给出调整建议。导出显示条数、百分比进度条和预计剩余时间，完成摘要保留；取消任务保留文件与部分清单，不弹普通错误。首次加载模型时预计时间可能波动。导出目录、会话排序/类型、识别/SILK与日期选项保存在本机 `workspace/ui-preferences.json`，相对导出路径统一基于软件所在目录。重连失败时保留原有已加载副本；翻页不再重复统计所有会话，导出数量使用单独的轻量查询。完整包、DirectML与模型均保留。

本版新增独立的会话导出页面，以及从“小芽·儿童语音伙伴 r5”实际复用的本地SenseVoice int8识别。完整部署包已包含模型和运行库，识别不联网、不使用大模型。WAV命名固定为 **`时间_唯一编号_识别文字摘要.wav`**，例如 `20261107-143520_0123456789abcdef01234567_今天下午一起出去走走.wav`。摘要最多40字，完整识别文字保存在CSV/NDJSON清单。空白或失败使用“未识别语音”，WAV导出成功与识别成功分别计数。

本版对照 Moect 的数据库字段和媒体流程补齐：支持无 salt 的 raw-key 字面量、大小写及扩展字面量；语音发送者优先按会话、服务器消息 ID 和时间关联，保留旧结构回退；补齐 SILK 的 LF/CRLF 头、结束标记与单包短语音处理。没有引入 Moect 应用或读取它的私有缓存，仍用本工具的独立工作进程、页认证、冻结副本和原件保留流程。用户反馈 Moect 可以导出，不等于本工具已通过该账号实测。

## 使用部署包

1. 完整解压到一个可写的文件夹，例如 `D:\工具\微信语音导出工坊`。双击 `WechatVoice.Workshop.exe`。需要 Windows 10/11 x64 和 .NET Framework 4.8；preview14 起部署包采用 C# 引擎，不用安装 Python。
2. 启动时工具按微信自身设置自动扫描本机账号并列出，直接在“微信账号”下拉框选择即可，可点“扫描账号”重新扫描。也可点“选择位置”手动指定：**单个账号文件夹**、其 `db_storage` 文件夹，或 `xwechat_files`（再从下拉框选账号）；不接受“手机备份”产生的加密备份包。
3. 勾选本人或已获授权账号，保持微信登录，点击“连接微信”。主界面自动刷新并优先选择内存占用最大的微信主进程。允许文件版本为4.*.*.*的Weixin.exe/WeChat.exe尝试；其他主版本、无效版本或无关进程拒绝读取内存。多进程需要人工指定时，展开“高级 / 诊断”。账号下拉框按最近使用排序；扫描不到的目录用“选择位置”指定，多账号时不会自动混合读取。
4. 工具自动准备并验证密钥，复制主库/WAL后在副本上解密、重放提交和整理目录，无需强制退出微信。若只找到部分，可打开更多目标会话后重连；复制中变化或校验失败最多重试三次，仍失败会列出原因。各库分别取得可验证副本，不承诺跨库同一时刻。
5. 左侧选择具体会话，点击“会话导出…”或双击会话，进入导出页。可按起止日期筛选（包含结束日）、查看数量、开启本地识别命名、选择是否额外保留SILK，再点“开始导出WAV”。主页面保留试听、分页和导出目录；进程选择、导入副本、选中项导出和详细日志收进“高级 / 诊断”。
6. 每次导出产生一个新的独立目录，包含 `.wav`、`语音清单.csv`、逐条 `progress.ndjson` 和最终 `manifest.json`；勾选保留原始SILK时另含 `.silk`。转换失败时原始SILK仍保留。取消任务产生 `partial.json`，已导出文件保留。识别失败不影响WAV，清单记录原因。

如果你已有**同结构的解密 SQLite 副本**，选择副本所在目录，可跳过准备密钥；这种导入不要求关闭无关的微信进程，但导入期间副本必须保持不变。

目录示例（仅说明结构，账号标识为示意）：

```text
某个账号目录/
  db_storage/
    contact/contact.db
    message/message_0.db
    message/media_0.db
```

不要移动或删除源目录。建议先用微信自带迁移/备份功能保留一份备份；本工具不会修改原库，但也不能恢复已从本机清理的语音、不能直接解析手机官方备份包。只能导出电脑当前实际存有的语音。

## 数据、正确性和限制

- 准备操作仅只读扫描用户选定的、版本匹配的一个 PID，最多 120 秒 / 2 GiB 可读内存。识别 SQLCipher 已存在的 raw-key / key+salt 字面量（ASCII/UTF-16、64～192 位 hex），最多验证 50000 个去重候选，逐个验证所选账号数据库的页 HMAC 后采用。无 salt 时只在所选账号数据库内验证。没有命中不做猜测；不注入、不抓取网络、不更改保护设置、不输出内存转储。
- 密钥仅以当前 Windows 用户 DPAPI 加密保存于 `workspace/keys`。不同 Windows 用户/电脑不能直接复用。密钥不会出现在命令行、日志或导出清单中。权限不足时请确认微信与工具由同一用户、同一权限级别启动；首版不会自行提权。
- 源库只读。输出放到程序旁边的 `workspace` 或你选择的导出目录；禁止放在源账号目录内。先复制稳定的主库/WAL对，主库和WAL都校验后重放到新副本；复制期间变化则重试，认证失败或WAL不完整时拒绝使用该库。
- 支持 SQLCipher4 的 4096 字节页 / 80 字节 reserve；未知加密参数和其他表结构需要另行适配。
- 语音从 `media_*.db / VoiceInfo.voice_data` 逐条读取。发送者通过**各消息分片自己的 Name2Id**，优先按会话哈希、`VoiceInfo.svr_id = 消息.server_id`、create_time 关联，服务器 ID 保持完整十进制字符串。缺少服务器 ID 的旧结构才回退到 local_id；明确不匹配的服务器 ID 不回退。歧义、缺消息库时标为“未知发送者”。会话无联系人资料时显示账号标识。
- 数据库未解出、字段不兼容会显示警告。目录里出现的语音数是本地成功读取到的数量，**不代表全部历史聊天**。群聊和自己发送的语音均以可核验的映射为准，无法核验时保持未知。
- 单个原库最多 32 GiB，总库最多 64 GiB / 512 个；目录最多 100 万语音。单条语音最多 8 MiB；WAV 为 24 kHz、16 位、单声道，解码最多 90 秒，每条子进程最多 8 秒。超限保留可读取的原始 SILK 并记录失败原因。
- 不覆盖已有导出。CSV 适当转义公式前缀；文件名移除 Windows 非法字符，并带唯一编号避免同时间/同名碰撞。
- `workspace/sessions` 包含解密后的数据库副本、联系人和预览音频，属于私密数据。请妥善保管，使用后可关闭程序再手动删除不再需要的会话。整个 `workspace` 不进入源码或部署包。
- 诊断放在 `workspace/diagnostics`，通过界面导出诊断 ZIP。仅保留请求编号、阶段、耗时、计数与结构化异常类型/错误码等白名单字段；不导出账号路径、密钥、语音文件名或识别正文，不收集旧的自由文本日志。引擎日志每文件 256 KiB 轮转并限制数量。
- 中文和空格路径已测试；程序启用 Windows 长路径支持，极端路径仍受系统设置和磁盘约束。

## 开发与构建

源码为 VS2022 标准 WinForms / .NET Framework 4.8 x64，窗体、Designer.cs、resx 分离；后台为 C# 独立工作进程（VoiceEngine），通过 stdin/NDJSON 通信，SILK 解码用自编译 silk.dll（SILK SDK C 源码见 `.deps/silk-sdk`），SQLite 用系统 winsqlite3。解码再隔离到有时限的子进程。窗体构造只初始化控件。旧 Python 3.12 worker 仍保留在构建系统中作回退（`./tools/build.ps1` 默认仍产出）。

打开 `WechatVoice.Workshop.sln` 可编译界面。完整构建需要 VS2022 的 .NET 桌面开发组件、Python 3.12 x64、PyInstaller 6.21.0 / hooks 2026.6。源码包内包含固定哈希的 4 个依赖 wheel，可离线提取；PyInstaller、VS 和 Python 开发环境需预先准备。

```powershell
# 在本项目目录运行，需要 VS2022 .NET 桌面开发和 C++ 桌面开发工具；Python 仅用于参考对照和构建
./tools/build.ps1 -Python 'C:\Python312\python.exe'
./tools/package.ps1 -Python 'C:\Python312\python.exe'
```

缺少 wheel 时可按锁文件下载（不会自动下载/执行 GitHub 项目）：

```powershell
python -m pip download --index-url https://pypi.org/simple --only-binary=:all: --require-hashes -r requirements-lock.txt -d .deps/wheels
```

`tests/test_core.py` 只使用生成的假账号、合成 SQLite / SQLCipher / WAL 和正弦波语音。`FormsCheck.cs` 区分 DesignSurface、实际消息循环的合成导出验收；**设计宿主通过不等同 VS2022 IDE 自动测试，合成数据库通过不等同真实微信版本兼容**。加密样本测试使用本机 SQLite C API 的 reserve_bytes 文件控制，缺少该开发 DLL 时会明确 skip，不能当成完成该项测试。

更多参考与许可见 `THIRD-PARTY-NOTICES.md`、`licenses/`；开发验证记录见 `docs/验证记录.md`。本工具没有后台遥测或云端上传功能。

源码包另带 `.deps/asr-kids` 固定资源和 `asr-resources.json`，无需重新下载模型。若从裸源码恢复，可运行 `python tools/import-kids-asr.py 小芽r5源码根目录`。本地识别在独立 `.NET Framework 4.8 x64` 子进程中运行，复用小芽UTF-8配置和CPU识别路径，同一批次复用模型；没有导入小芽的个人设置、密钥、录音、聊天、TTS或唤醒业务。
