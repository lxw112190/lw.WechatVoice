# 收藏语音

本轮在本地 `lw.WechatVoice` 克隆中开发，源码准备版本 1.1.1；未自动提交、推送或发布。

## 使用

1. 在电脑微信打开“收藏”，打开需要的项目，让附件下载到本机。
2. 工坊选择本人/已授权账号，确认授权，点击“收藏语音”。保持微信登录时只读准备选定进程对应凭据；没有微信进程时可读取已有凭据或解密副本。
3. 列表按收藏项目分组，标题可用左侧搜索筛选；日期依据收藏库的 update_time，界面显示“收藏时间”。
4. 双击试听、右键导出选中，或点击“导出收藏…”打开导出窗口。“全部收藏”可跨页导出当前日期范围的全部语音，也可在左侧选择某个收藏项目。识别命名与分页缓存沿用既有流程。
5. “[含缺失原件]”表示该项目至少一条语音缺失或无法唯一匹配；原始大小为零的行无法试听，导出会计为失败。下载源附件后重新点击“收藏语音”。

当前支持本工具 SILK 解码路径。若缓存为真正的 AMR/MP3/M4A/WAV 等其他编码，转换失败时仍保留原始字节；不会仅改扩展名冒充 WAV。不联网下载收藏，不恢复已清理内容。

## 实现与边界

- 在私有目录冻结 `favorite/favorite.db` 和可用的 contact/message/media 数据库，延续页认证、WAL 与 SQLite 校验。
- `fav_db_item` 读取 local_id/type/update_time/content/fromusr/realchatname/flag；排除非零 flag。识别类型 3、14、18 的语音块，处理嵌套 recorditem。
- XML 禁用 DTD/外部实体，长度、深度及节点数有界。类型/格式未知不猜测。
- 只遍历选定账号 `business/favorite/data` 与 `temp`，跳过目录链接，按实际内容 MD5 核对 fullmd5。缓存中的不透明文件名和 XML 附件路径均不作为可信来源。
- 原消息回退只查询冻结 VoiceInfo 中的 svr_id；保留 64 位整数精度。存在 fullmd5 时同时核对内容；多种不同内容或查询超限时保留缺失状态。
- 匹配音频保存到会话的 favorite-audio 目录，载入时再次校验 SHA256。成功读取后源缓存变化不影响当前会话。快照、缓存和输出不进入 Git 或发布包。
- 扫描限制为 10 万缓存项 / 4 GiB 字节、单文件 8 MiB；允许取消。各数据库独立快照，不承诺跨库同一时刻。

## 上游格式依据

对照 [Moect core/favorites.py](https://github.com/lxw112190/Moect/blob/7498e9f21ab283edb55a5d6a2e17c7ad696cf168/core/favorites.py)（固定提交 `7498e9f21ab283edb55a5d6a2e17c7ad696cf168`，GPL-3.0），核对收藏表字段、语音类型枚举、嵌套记录、缓存目录与 svr_id 关联。使用项目自有 C# 快照、查询、解码与导出实现，未复制上游 Python/UI 或执行上游应用。

## 验证

`tests/favorites_check.py` 只生成假账号、正弦波 SILK 和 SQLite。覆盖嵌套记录、过滤删除项、XXE 拒绝、伪造缓存文件名、UINT64 消息 ID、歧义与缺失、时间/空 ID 筛选、冻结副本试听/导出、仅收藏库账号和源数据库字节不变。测试挂入 build.ps1；真实账号和微信版本兼容仍需用户授权复测。
