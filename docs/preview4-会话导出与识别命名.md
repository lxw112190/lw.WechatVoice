# preview4：会话导出与本地识别命名

日期：2026-11-07。

## 使用流程

1. 微信保持登录，选择本人账号与4.0.5.16进程，点击“连接微信 / 刷新语音”。已有密钥或解密库可使用另一读取按钮。
2. 选定具体会话，点击“会话导出…”或双击会话。全部会话入口不能直接发起批量导出，避免把其他会话混进结果。
3. 导出页可查看数量、按起止日期筛选（结束日包含整天），默认启用本地识别，默认只保存WAV，可另勾选保留SILK。选中项导出会继续限制到所选ID。
4. 文件名固定为 `时间_唯一编号_识别文字摘要.wav`。时间为消息本地时间，唯一编号为语音索引的24位ID，摘要清除Windows非法字符、控制符和首尾空格/点，最多40字。完整识别文字写入CSV及NDJSON，不把长句全部塞进文件名。
5. 没有文字、模型不可用或识别失败，仍保存 `时间_唯一编号_未识别语音.wav`。统计分别展示WAV成功/失败、识别成功/未完成。语音解码失败时保留原始SILK；取消保留已有结果并写partial.json。

识别可能听错，文字只是可检索的文件名，原始声音是依据。源数据库和已冻结副本保持原样，不反写微信。

## 实际复用小芽 r5

来源为用户提供的 `KidsVoice-Workshop-20261102-r5-source`。复用其`NativeSpeechApi.cs`中的UTF-8配置/原生句柄释放，以及SpeechEngine的SenseVoice CPU识别路径。`tools/import-kids-asr.py`只复制明确允许的识别模型、字表、管理程序集、必要DLL及许可证，记录原始SHA256；不会读取个人设置、密钥、录音或聊天。

识别模型：SenseVoiceSmall int8，SHA256 `c71f0ce00bec95b07744e116345e33d8cbbe08cef896382cf907bf4b51a2cd51`；sherpa-onnx 2.0.1。另起.NET Framework4.8 x64的AsrWorker，按批次复用模型，CPU两线程；输入限90秒PCM16单声道WAV，结果限2000字/64KiB。工作进程IPC只用stdin/stdout，每条90秒上限，取消终止本次识别子进程，主界面不加载推理DLL。保留小芽的CRT预加载、显式UTF-8和版本/空句柄检查，不经过LPStr传中文路径。

完整部署包和源码包均含固定模型/运行库，正常使用不下载、不联网、不调用云端ASR、大模型或DeepSeek。复用运行库构建依赖DirectML，因此随带依赖和对应许可；当前识别选择CPU，不宣称GPU加速。
