# 右键导出与本页识别缓存

2026-11-08，preview11。

## 使用

- 在语音列表Ctrl/Shift多选后右键，点“导出选中的语音…”。右键已选行保留多选，右键未选行只选该行，空白处不弹出导出菜单。全部会话中也支持按所选ID导出，进入导出页后可查看数量、日期与识别选项。
- 分页栏点击“识别本页语音”，仅识别当前页最多50条。列表新增识别文字与状态，鼠标停在行上可查看完整文字。任务逐条保存，可取消。
- 翻页或切换会话再回来会恢复已识别文字；再次识别复用成功与空白结果，失败项重试。导出时勾选识别命名，也优先复用缓存。

## 缓存范围

当前数据副本session中创建私有transcripts.sqlite，不写微信源库。缓存绑定记录ID、音频内容SHA256和固定模型/识别配置标记。不同副本/账号互不读取缓存；重新连接产生新副本后需要重新识别，不承诺跨副本迁移。仅刷新/翻页不会清理现有缓存。

成功结果包括“已识别”和“无识别文字”。错误只保存可重试状态，不将错误当作成功缓存。每条事务提交后才报告完成；取消不会丢掉已经完成的条目。文字为本地明文缓存，不进入诊断包、源码包或部署包。用户可自行保管整个工作目录。

缓存损坏时语音列表仍可读取，导出仍可重新识别；本页识别会报告失败，不静默删除缓存或源文件。可重新连接建立新的数据副本重试。

实际部署WinForms消息循环检查本页识别按钮、缓存回显、右键保留多选、选中2条实际导出和原会话3条导出；公开语音用实际模型验证本页识别、跨工作进程缓存和导出命名。使用合成账号与公开样例，不读取私人微信数据；不表示异机4.2.0.13连接问题已修复。
