# preview15：C# 与原生库运行链路修复

2026-11-10。在 preview14 的 C# 引擎上修复审查发现的问题，部署运行仍不需要 Python；模型和 DirectML 原样保留。Python 只用于构建期参考对照与测试，未重新加入部署包。

## 修复内容

- **识别结果错位**：识别超时、取消、异常响应、组件提前退出时，结束并回收当前 ASR 进程。下次识别创建新进程及独立响应队列，旧请求不能污染新语音的文字和缓存。输出在读入时限制长度，stderr 持续排空，组件退出立即报错。保留结构化原生错误码。
- **解码取消后继续写文件**：所有退出路径都等待本工具启动的解码子进程结束，再返回取消；不会在 partial 清单生成之后由遗留进程继续写 WAV。回归检查增加返回后的延迟检查，避免只检查瞬间文件不存在而漏测。
- **索引逐条提交导致慢**：联系人、消息和语音索引在同一个私有事务内创建；完成后提交，取消/异常关闭连接时回滚。未关闭同步写入，也未改变源数据库。同一台电脑、同一份 3,000 条合成语音：Python 参考 0.345 秒，C# 修复前 23.772 秒、修复后 0.543 秒，约快 44 倍。这是一次本机对比，不承诺所有机器和数据量都达到同样速度。
- **路径中 `#`、`%` 和单引号**：统一转换为转义后的绝对 file URI，缓存 ATTACH 使用绑定参数；同时修复打开数据库失败和 SQL 错误字符串的原生内存释放。
- **源码包无法独立重建原生库**：纳入 138 个固定 SHA256 的 SILK SDK 文件、项目导出 shim、来源清单和 tools/build-silk.bat。脚本自动寻找 VS2022 C++ 编译工具，并检查真实编译退出码，拒绝复用失败前的旧 DLL。源码包不含本机 obj/dll 输出。依赖清单记录实际部署的 C# 引擎与 DLL，而不再把 Python 回退产物列为当前运行文件。

## 回归入口

- `tools/build.ps1 -SkipWorker`：Python 参考测试、C# 模块对照、真实模型识别对照、设计器和消息循环测试；新增 EngineRobustnessCheck 检查 ASR 超时重启、EOF、响应上限、stderr、取消、特殊路径及索引回滚。
- `tools/package.ps1`：最终目录 IPC 与 GUI 合成导出、源码/部署 ZIP。
- `tools/verify-package.py 部署.zip`：实际 ZIP 清除 Python 环境后运行，检查哈希与语音导出。
- `tools/verify-source.py 源码.zip`：实际源码 ZIP 解压到新目录，验证固定源文件并重新编译 SILK 和整个解决方案。

全部使用合成数据库、合成进程和测试音频。本轮没有读取真实微信账号、聊天或微信进程内存；C# 引擎仍需用户授权后的真实账号复测，不把早期 Python 引擎的实测当作本版兼容证明。
