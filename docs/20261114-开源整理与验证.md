# lw.WechatVoice 开源整理与验证

参考同作者的 lw.HomeNAS、lw.PPOCR.OpenCVDNN、lw.PPOCR.Inference：采用中文优先和英文 README、明确的源码/第三方/测试/工具/文档目录、Windows CI 与完整可下载包。保留既有 VS 方案、程序文件名和业务流程。

已加入 MIT 自有代码许可及第三方许可区分、参与说明、隐私反馈说明、Issue/PR 模板、Git 换行规则、VERSION 和更新记录。SDK 源码与 ASR 字表/运行库保留原始字节，防止 Git 换行转换导致哈希失败。公开源码采用白名单导出，模型、真实数据库、密钥、语音、日志与缓存不进 Git。

## 本机实际验证

- `tools/check-repository.py`：公开树边界、敏感路径/凭据形态检查、文件大小、固定 SDK 与 ASR 文件哈希通过。
- `tools/restore-dependencies.py --verify-only`：既有模型、运行库、138 个 SDK 源文件和四个固定 wheel 通过。
- `tools/build.ps1 -SkipWorker`：54 项 Python 合成测试、三个项目编译、DesignSurface、UI 交互、29 组 C#/Python 快照逐字节对照、源只读/取消/重试、诊断字段、合成进程扫描、索引/排序/缓存、SILK 字节对照与导出回归通过；真实本地模型参与合成导出识别与命名对照。
- `tools/package.ps1`：打包后的 IPC、诊断白名单和合成 GUI 导出流程通过。
- `tools/verify-package.py`：实际 ZIP CRC、逐文件哈希、私密文件排除、只保留 System32 的环境下引擎自检及 9 项音频导出通过。
- `tools/verify-source.py`：实际完整源码 ZIP 解压后的 SILK 与整个解决方案独立编译通过。
- `tools/verify-repository.py`：Git-only ZIP 无 .deps/bin/obj/workspace，解压后仅补入声明的模型和 wheel 下载缓存，离线恢复其余资源、全方案和 SILK 独立编译通过。
- 工作流 YAML 解析和 job 依赖核对、公开文档相对链接检查通过。截图来自上述合成 GUI 测试。

## 验证边界

没有读取真实账号数据库或微信进程内存。本轮整理不代表修复了真实 4.2.x 账号，也不修改既有真实账号兼容结论。

Hugging Face 托管页面的模型大小/哈希与本地模型一致；本机直连联网检查超时，因此未宣称完成干净环境联网下载或 GitHub Actions 实际运行。已验证从固定缓存恢复的路径，首次推送仍需在 GitHub 验证联网恢复、Runner 和附件发布。没有创建远程仓库、提交、推送或发布 Release。
