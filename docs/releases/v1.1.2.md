# lw.WechatVoice v1.1.2

本版修复深目录下创建语音库快照失败的问题，并纳入自 v1.0.0 以来的收藏语音和早期 SILK 兼容改进。

## 更新内容

- 修复程序解压在较深目录时可能出现的 `SNAPSHOT_RETRIES_EXHAUSTED`。语音库快照、索引、试听和导出支持含中文、空格、`#`、`%` 的长路径。
- 支持试听和导出末尾带短全零填充的早期微信 SILK 录音。选择保留 SILK 时，原始字节完整保留。
- 新增「收藏语音」，可读取单独收藏及聊天记录、笔记中嵌套的语音，支持试听、按日期筛选和批量导出。缺少原件或匹配有歧义时会明确提示。

## 下载与运行

- 普通用户下载 `WechatVoice-Workshop-1.1.2-win-x64.zip`，包内含运行库和离线 SenseVoice 模型。
- `WechatVoice-Workshop-1.1.2-source.zip` 包含完整开发源码及固定依赖。
- `lw.WechatVoice-git-source.zip` 是精简源码包，模型可按包内 README 恢复。
- 各 ZIP 配有同名 `.sha256` 校验文件。

先把 Windows 部署包完整解压到新目录，再运行 `WechatVoice.Workshop.exe`。需要 Windows 10 或 11 x64 和 .NET Framework 4.8。

## 验证范围

从最终部署 ZIP 复测了 310 字符以上路径的快照、试听和 WAV 导出，以及收藏语音和离线识别。验收使用合成数据库和公开语音样本，真实账号的结果以对应环境实测为准。
