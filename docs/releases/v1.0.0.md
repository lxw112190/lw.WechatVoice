# lw.WechatVoice v1.0.0

微信语音导出工坊首个正式发布版。

## 主要功能

- 扫描并选择本人或已授权的电脑微信账号，按会话与日期筛选本地语音。
- 搜索、排序、分页与试听，支持选中导出和会话批量导出。
- 导出可播放 WAV，可保留原始 SILK，生成 CSV / NDJSON 清单。
- 本地 SenseVoice 识别、分页缓存及“时间_唯一编号_识别文字摘要.wav”命名。
- 独立 C# 引擎与原生 SILK 解码，不需要安装 Python 或调用云端服务。
- 白名单诊断包、只读来源与独立工作目录。

## 下载哪个文件

- `WechatVoice-Workshop-1.0.0-win-x64.zip`：普通用户下载这个完整 Windows 包，带模型和运行库。
- `WechatVoice-Workshop-1.0.0-source.zip`：完整离线开发源码与固定依赖。
- `lw.WechatVoice-git-source.zip`：准备放入 Git 的精简源码树，模型需按文档恢复。
- `.sha256`：相应 ZIP 的 SHA256 校验值。

完整解压后运行 `WechatVoice.Workshop.exe`，需要 Windows 10/11 x64 与 .NET Framework 4.8。不要只复制 EXE。当前识别使用 CPU，保留 DirectML DLL 用于满足既有运行库依赖。

## 本次修整

修复 Windows CI 的长短路径测试误报，以及 UTF-8 控制台下子进程输入 BOM 导致独立解码失败。构建流程覆盖合成数据库、WAL、逐字节解码对照、取消、真实本地模型识别及实际包验证。

## 使用范围

工具只能导出电脑上实际存在的语音，不能恢复本机已清理的内容，也不能直接读取手机官方备份包。面向 Windows 微信 4.x 按实际数据验证尝试连接，不承诺所有版本、账号或历史数据均兼容。

当前引擎和有效页修复通过 CI 合成回归，真实账号复测仍待完成；早期引擎的 4.0.5.16 / 4.1.0.30 授权验证不能代替当前版本验收。连接失败请使用界面导出诊断包，勿公开上传数据库、密钥或真实语音。
