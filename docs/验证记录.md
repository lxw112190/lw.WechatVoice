## Moect 1.3.1 语音对照（2026-11-20）

对照上次收藏语音参考的 `7498e9f` 与 Moect 1.3.1 的 `c954e11`。上游改进了早期 SILK 的末尾补齐兼容，并在通用会话预览中支持 FLAC 文件附件。当前同步范围是语音消息和收藏语音的 SILK 解码。 [Moect 1.3.1 发布说明](https://github.com/lxw112190/Moect/blob/c954e112b8501548e81d95f21cc865b935610328/docs/release-1.3.1.md)

C# 引擎和 Python 回退均在完整 SILK 包之后识别 2 至 256 字节的偶数长度全零填充。送入解码器的只包含已验证的数据包，保留的 SILK 原件逐字节一致。22 个合成编解码用例通过，覆盖单包、多包、LF/CRLF 头、最小和最大填充，以及奇数长度、超限、混入非零字节、包截断等拒绝场景。Release x64 编译、隔离进程解码和合成会话批量导出通过。对比确认带填充和原始未填充的录音产生相同 WAV。

用交付目录结构重新打包并解压测试引擎和 SILK DLL，合成收藏语音试听、4 条 WAV 导出及原件校验通过。较深的临时目录触及现有引擎的收藏快照路径限制，收藏回归在较短的临时目录运行。此次验收使用合成音频和数据库。
