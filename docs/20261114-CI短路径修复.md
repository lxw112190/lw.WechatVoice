# Windows CI 的长短路径断言修复

失败运行：[43593934790](https://github.com/lxw112190/lw.WechatVoice/actions/runs/43593934790)，提交 `e4b404553af557ecb7072b83dcc31f2390a41b13`。

`test_connect_uses_only_explicit_pid_and_account` 的账号目录断言失败：同一目录经来源解析后显示为长用户名路径，而 tempfile 使用的 TEMP 路径带 Windows 8.3 用户名别名。两者实际指向相同目录，直接比较 Path 字面值造成误报。55 项中的新增项用于回归；原失败运行共执行 54 项，仅此一项失败。

测试改为 `Path(folder).samefile(source)`，PID 仍必须等于明确指定值。新增路径别名测试同时确保不是另一个账号，覆盖含父目录的等价路径，并在系统返回有效结果时使用 GetShortPathNameW 取得短路径别名。不改变应用行为，不放宽进程/账号范围，不跳过认证或关闭测试。

本机 E 盘没有返回不同拼写的 8.3 别名，因此本机能验证等价路径和不同账号区分；实际 Runner 的短路径场景仍由再次推送后的 CI 验证。运行 Python 参考回归使用 build.ps1 相同的 `.deps/vendor` PYTHONPATH，供隔离音频子进程加载固定依赖。

修复后本机 55 项 Python 合成回归全部通过（15.793 秒），公开源码检查和 `git diff --check` 通过。未提交或推送；GitHub 修复后的运行结果尚待验证。
