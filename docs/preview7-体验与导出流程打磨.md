# preview7：体验与导出流程打磨

日期：2026-11-08。保留完整模型、DirectML和现有运行依赖，不拆分、不精简资源。

## 日常操作

- 主操作按钮统一绿色。双击单条语音试听；切换会话、翻页或开始导出会停止试听。未选中语音时试听按钮不可用。
- 会话导出页增加“全部日期”“最近7天”“最近30天”。快捷日期包含今天和结束日全天。日期框仅在范围筛选开启时可编辑，零条时禁用开始并提示调整范围。
- 输出目录、会话类型/排序、是否识别、是否保留SILK和日期保存在本机 `workspace/ui-preferences.json`。不保存搜索词、会话标识、语音正文、密钥。文件损坏时回退默认值并写诊断，保存使用同目录临时文件加原子替换。
- 相对输出目录由exe目录解析，不再受工作进程所在的 `engine` 目录影响。
- 同来源重连失败继续保留已加载副本；来源改变仍清空旧会话和搜索。新会话列表读取失败时清空旧可见行，避免在新会话范围下误操作旧列表。

## 导出反馈和速度

- 导出之前单独统计过滤范围，显示总数、已处理数、WAV成功/失败、进度条和预计剩余时间。预计值按已完成条目的平均耗时推算，首次模型加载、语音长短和电脑负载会影响估算，不是速度保证。
- 完成后保留结果摘要与进度，不被通用“就绪”覆盖；取消不弹普通错误，等待中的取消文字不会被旧进度覆盖。排队的UI回调带操作代次，完成/关闭后失效。
- 清单增加 `total`、`processed`、`remaining`、`elapsed_seconds`。识别过程中取消时，已经生成的本条SILK/WAV登记到CSV/NDJSON，标记取消；本条不冒充成功，批次写partial.json而不是manifest.json。
- 新增 `count` 动作：只执行COUNT，不读取语音条目或会话汇总。翻页传 `include_contacts:false`，仅首次加载需要会话汇总。过滤条件由同一函数处理，保持数量与实际导出一致。
- 修复显式空 `ids:[]` 曾被当成未限制选择的问题，结果现在是零条；非法/倒置日期拒绝，时间戳0仍是有效边界。
