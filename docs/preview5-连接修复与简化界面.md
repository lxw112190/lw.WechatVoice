# preview5：连接修复与简化界面

2026-11-07。

## 本轮定位

旧部署包日志显示失败发生在获取密钥。经用户授权核对Moect账号路径元数据，确认先前选择的历史账号目录与Moect成功副本对应账号不同；取得用户新选择后，在真实4.0.5.16微信上成功取得该账号所需的6个数据库密钥，均通过页HMAC认证。没有读取或导入Moect的keys.json。

接着复现了第二个错误：真实WCDB的WAL有固定预分配空间，并保留checkpoint前的旧代际帧，物理长度不一定是32+N×4120。旧代码先要求物理长度对齐，从而把这些有效数据库全部挡住。现按WAL文件头、salt代际和提交边界读取：首次旧代际salt是逻辑结尾，后面的预分配区不当当前帧；逻辑结尾前的完整帧仍做checksum、页HMAC、提交重放。没有通过禁用认证或忽略当前代际损坏来放行。

## 连接实现

- 自动按内存占用排序，连接按钮刷新并默认选微信主进程；高级设置可指定进程。每个进程仍检查可执行文件和4.0.5.16版本。
- 在公开Moect格式布局基础上独立实现Config.Cipher配置对象读取，加上原始字面量兼容和最多64次受限派生。候选必须认证所选账号数据库，不会按字符串形状直接采用。
- 扫描仍限120秒和累计2GiB，按私有可写区域优先，块边界保留重叠。取消可在读取/验证中生效。输出仅为阶段/数量，不记录密钥或内存转储。
- 目录含多个账号时必须选择具体账号；后端也拒绝把xwechat_files里的多个账号混合读取。记住最近一次用户连接路径，只存工作目录、不随包分发。

## 界面

正常界面只保留账号下拉框、选择位置、连接微信、会话/语音列表、试听、会话导出、输出位置和进度。进程、刷新进程、导入副本、选中项导出和日志收进“高级 / 诊断”。日期范围仍在独立导出页，避免主页面重复放同一套筛选。

识别命名沿用小芽SenseVoice离线识别，固定为 `时间_唯一编号_识别文字摘要.wav`，无识别文字时保留WAV并用“未识别语音”命名。

## 验证

- 37项核心测试通过，新增Config.Cipher raw/master、跨块、错误账号/指针、取消/派生上限，以及预分配旧WAL与提交后旧代际尾部回归；原有当前代际坏checksum和截断拒绝继续通过。
- 在一个用户指定真实账号上，6/6数据库通过副本校验并读到语音目录，issues为空。具体账号路径、密钥、目录索引和语音数量保存在忽略的本地工作目录，不放入公开源码记录。
- 用新版实际部署目录中的独立引擎，从上述获授权账号限制选取3条语音，3/3导出WAV、3/3返回本地识别文字并完成时间_ID_摘要命名。没有把联系人、语音文件名或识别正文输出到测试报告；只保留本地私有结果，不随包分发。该小样不代表全量历史或识别文字绝对准确。
- GUI与最终部署包继续用合成账号验收，不把真实联系人、截图、录音或识别文字放入包。仅对这一个获授权账号声明连接实测，不外推到其他版本/账号。
