# 语音信息列表排序

2026-11-08，preview12。

点击右侧语音列表的列标题排序，再次点击同一列切换升序/降序；标题箭头与分页栏显示当前条件。支持发送时间、发送者、识别文字、识别状态、会话、原始大小、本地编号。首次默认发送时间升序；软件记住最后一次排序选择。

排序覆盖当前会话/筛选范围的全部语音，先在本地索引排序再取每页50条，翻页继续使用同一顺序。切换排序回到第一页；原先选中且仍在第一页的记录按ID恢复，移出当前页的不保留隐形选择。右键导出继续以当前实际选择ID为准，不会因行序改变而导出另一条。

大小、时间和编号使用原始数据库数值排序，不比较显示的KB字符串。文字使用SQLite NOCASE比较（英文忽略大小写，中文按Unicode次序，不承诺拼音顺序）。相同排序值按时间和记录ID稳定排列。识别状态升序顺序为已识别、无识别文字、未识别、失败；降序反转分组。

识别列只读当前副本的识别缓存进行排序，不会自动识别未处理语音，也不改写已有结果。完成识别后，若正在按识别文字/状态排序，刷新时记录可能因值更新而换页。坏缓存仍允许语音列表读取并记录缓存问题。诊断包不包含识别文字。

验证包括113条记录跨三页的全局数值排序/筛选/无重复、缓存文字和状态在分页前排序、非法排序参数拒绝；设置记忆；实际部署WinForms列头排序方向、选中ID恢复、缓存回显及原有右键导出。本轮仅合成账号和公开语音，不读取私人微信数据，也不表示异机4.2.0.13连接失败已解决。
